# AIDEX Dashboard Layout Design

## Introduction

The Dashboard Layout is the main interface of the AIDEX (AI Digital Evidence Intelligence & Investigation System). It provides a structured and user-friendly environment where users can access different modules according to their roles.

The layout is designed to improve navigation, increase productivity, and provide quick access to important cyber crime investigation data.

---

## Purpose of Dashboard Layout

The dashboard layout is designed to:

- Display important system information
- Provide easy navigation
- Show recent activities
- Display case statistics
- Provide quick access to evidence
- Improve user experience
- Support role-based access

---

## Main Dashboard Structure

The dashboard consists of the following sections:

1. Header
2. Navbar
3. Sidebar
4. Main Content Area
5. Dashboard Cards
6. Tables
7. Quick Actions
8. Notifications
9. Footer

---

## Header

The Header is displayed at the top of every dashboard page.

Contents:

- AIDEX Logo
- Project Name
- Current Date and Time
- User Role
- User Profile

Purpose:

- Display project identity
- Display logged-in user information
- Provide quick navigation

---

## Navbar

The Navbar contains:

- Search Box
- Notifications
- Profile Menu
- Logout Button

Purpose:

- Search records
- View notifications
- Access profile
- Logout securely

---

## Sidebar

The Sidebar provides navigation links.

Menu Items:

- Dashboard
- Cases
- Evidence
- Reports
- AI Analysis
- Users
- Profile
- Settings
- Logout

Purpose:

- Navigate between modules
- Display role-based menus
- Improve accessibility

---

## Main Content Area

The Main Content Area displays the selected page.

Examples:

- Dashboard Overview
- Case Details
- Evidence Details
- Reports
- AI Results
- User Management

---

## Dashboard Cards

Dashboard Cards display important statistics.

Example Cards:

- Total Cases
- Open Cases
- Closed Cases
- Pending Cases
- Total Evidence
- Verified Evidence
- Reports Generated
- Active Users

Each card contains:

- Icon
- Title
- Count
- Description

---

## Tables

Tables display detailed records.

Examples:

- Recent Cases

- Reports
