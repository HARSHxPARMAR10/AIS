# AIDEX Evidence Upload Design

## Introduction

The Evidence Upload Module allows authorized users to upload digital evidence related to cyber crime investigations.

The system securely stores evidence and links it to the appropriate case.

---

## Purpose

- Upload digital evidence
- Maintain integrity
- Store files securely
- Link evidence with investigation cases

---

## Types of Evidence

- Images
- Videos
- Audio Files
- PDF Documents
- DOCX Documents
- ZIP Files
- Screenshots
- Log Files

---

## Upload Workflow

Login

↓

Open Assigned Case

↓

Click Upload Evidence

↓

Select Evidence Type

↓

Choose File

↓

Validate File

↓

Upload Successfully

↓

Generate Evidence ID

↓

Store in Database

↓

Display Success Message

---

## Validation Rules

Maximum File Size

Allowed Extensions

## Expected Output

Evidence uploaded successfully and linked with the selected case.
