# AIDEX Update Profile Page

## Introduction

The Update Profile Page allows authenticated users to modify their personal information while keeping official account details secure. The page follows the AIDEX design guidelines and provides a responsive user interface.

---

## Objectives

The Update Profile Page is designed to:

- Update personal information
- Upload or change profile photo
- Maintain data consistency
- Improve user experience
- Protect official account information

---

## Editable Fields

The following fields can be updated by the user:

- Full Name
- Email Address
- Phone Number
- Department
- Profile Photo

---

## Protected Fields

The following fields are read-only and cannot be modified by the user:

- Username
- Badge ID
- User Role

These fields are managed only by the system administrator.

---

## User Interface Features

The page includes:

- Professional Header
- Profile Photo Preview
- Bootstrap Form Controls
- Responsive Layout
- Save Changes Button
- Cancel Button
- Validation Messages

---

## Security Features

- User Authentication Required
- CSRF Protection
- Django Form Validation
- Secure File Upload
- Session Validation

---

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Django Forms
- Django Template Engine

---

## Expected Result

The Update Profile Page enables users to safely update their personal information while preserving the integrity of official account data.
