# AIDEX User Profile Page

## Introduction

The User Profile Page displays complete information about the currently logged-in user. It provides a professional dashboard where users can review their personal and official details.

---

## Objectives

The User Profile Page is designed to:

- Display user information
- Show profile photograph
- Display assigned role
- Display department details
- Display badge information
- Provide profile update option

---

## Displayed Information

The Profile Page displays:

- Profile Photo
- Full Name
- Username
- Email Address
- Phone Number
- Department
- Badge ID
- User Role
- Account Status
- Date Joined
- Last Login

---

## Features

The page contains:

- Professional Header Section
- Circular Profile Image
- Role Badge
- Information Cards
- Dashboard Button
- Update Profile Button
- Logout Button
- Responsive Layout

---

## Responsive Design

The Profile Page is fully responsive for:

- Desktop
- Laptop
- Tablet
- Mobile Devices

---

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Django Template Engine

---

## Expected Result

The User Profile Page provides a clean, modern and responsive interface that allows users to easily view their account information.
