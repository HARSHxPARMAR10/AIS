# AIDEX Case Assignment

## Introduction

The Case Assignment Module is responsible for assigning cyber crime investigation cases to authorized investigators.

Proper case assignment ensures balanced workload distribution and efficient investigation.

---

## Objectives

The main objectives are:

- Assign Cases to Investigators
- Maintain Assignment History
- Improve Investigation Efficiency
- Track Investigator Workload
- Maintain Accountability

---

## Assignment Process

```text
Administrator
      ↓
Create Case
      ↓
Assign Investigator
      ↓
Investigator Accepts Case
      ↓
Investigation Starts
```

---

## Assignment Information

Each assignment contains:

- Assignment ID
- Case ID
- Investigator ID
- Investigator Name
- Assignment Date
- Assigned By
- Current Status

---

## Assignment Rules

- Every case must have one assigned investigator.
- One investigator may handle multiple cases.
- Assignment history must be recorded.
- Only administrators can assign cases.
- Investigators cannot assign cases to themselves.

---

## Assignment Status

Supported Status:

- Assigned
- Accepted
- In Progress
- Completed
- Reassigned

---

## Advantages

- Organized Investigation
- Better Work Distribution
- Easy Tracking
- Improved Accountability
- Secure Assignment Process

---

## Expected Result

Every cyber crime case should be assigned securely to an authorized investigator with complete assignment history.
