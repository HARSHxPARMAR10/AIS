# Evidence Verification Design

## Introduction

Every uploaded evidence must be verified before it becomes available for investigation.

---

## Verification Process

Evidence Upload

↓

Generate Hash

↓

Compare File

↓

Verify Integrity

↓

Approve Evidence

↓

Available for Investigation

---

## Verification Methods

SHA-256 Hash

File Size Check

Extension Validation

Timestamp Verification

---
