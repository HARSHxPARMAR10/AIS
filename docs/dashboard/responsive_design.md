# AIDEX Responsive Dashboard Design

## Introduction

The AIDEX Dashboard is designed using responsive web design principles to ensure proper functionality on desktops, laptops, tablets and mobile devices.

The responsive layout provides a consistent user experience across different screen sizes.

---

## Objectives

The responsive dashboard aims to:

- Support multiple screen sizes
- Improve user experience
- Maintain consistent layout
- Reduce scrolling
- Increase accessibility
- Provide better navigation

---

## Supported Devices

- Desktop Computer
- Laptop
- Tablet
- Mobile Phone

---

## Desktop Layout

Screen Width:

- 1200px and above

Features:

- Full sidebar
- Full navigation bar
- Four dashboard cards in one row
- Large tables
- Complete charts

---

## Laptop Layout

Screen Width:

- 992px to 1199px

Features:

- Sidebar remains visible
- Three dashboard cards per row
- Responsive tables
- Search bar visible

---

## Tablet Layout

Screen Width:

- 768px to 991px

Features:

- Collapsible sidebar
- Two dashboard cards per row
- Compact navigation
- Horizontal table scrolling

---

## Mobile Layout

Screen Width:

- Below 768px

Features:

- Hidden sidebar
- Menu icon navigation
- Single dashboard card per row
- Responsive forms
- Responsive tables

---

## Bootstrap Grid System

Desktop

- col-lg-3

Tablet

- col-md-6

Mobile

- col-sm-12

Example:

col-lg-3 col-md-6 col-sm-12

---

## Responsive Components

### Sidebar

- Visible on desktop
- Collapsible on tablet
- Hidden on mobile

### Navbar

- Search box
- Notification icon
- Profile menu
- Logout button

### Dashboard Cards

- Total Cases
- Pending Cases
- Evidence
- Reports

Cards automatically resize according to screen size.

---

## Responsive Tables

Tables support:

- Horizontal scrolling
- Dynamic width
- Responsive columns

Displayed Information:

- Case ID
- Case Title
- Status
- Assigned Officer
- Date

---

## Responsive Forms

Forms include:

- Login Form
- Registration Form
- Evidence Upload Form
- Case Form

Features:

- Full width inputs
- Responsive buttons
- Mobile friendly spacing

---

## Responsive Images

Images should:

- Maintain aspect ratio
- Resize automatically
- Support multiple resolutions

---

## Accessibility

The dashboard should provide:

- Readable fonts
- Keyboard navigation
- Proper color contrast
- Large clickable buttons
- Responsive menus

---

## Browser Compatibility

Supported Browsers:

- Google Chrome
- Microsoft Edge
- Mozilla Firefox

---

## Expected Result

The AIDEX Dashboard should remain responsive, user-friendly, secure and consistent across all supported devices while maintaining the same functionality on desktop, tablet and mobile platforms.
