# AIDEX Evidence Lifecycle

## Introduction

The Evidence Lifecycle describes every stage of digital evidence from collection to archival within the AIDEX system.

Each stage ensures that evidence remains secure and legally acceptable throughout the investigation.

---

## Evidence Lifecycle Diagram

```text
Collect
      ↓
Upload
      ↓
Verify
      ↓
Analyze
      ↓
Approve
      ↓
Store
      ↓
Archive
```

---

## Stage 1 – Collection

Digital evidence is collected from:

- Computer
- Mobile Device
- CCTV
- Email
- Cloud Storage
- Network Devices

---

## Stage 2 – Upload

The investigator uploads evidence to the AIDEX system.

The system records:

- Evidence ID
- Case ID
- Upload Date
- Investigator Name

---

## Stage 3 – Verification

The system verifies:

- File Integrity
- SHA-256 Hash
- Metadata
- File Format

---

## Stage 4 – AI Analysis

AI performs:

- OCR Analysis
- Metadata Analysis
- Duplicate Detection
- Content Analysis

---

## Stage 5 – Approval

The Cyber Officer reviews and approves the evidence.

Only verified evidence proceeds to the next stage.

---

## Stage 6 – Storage

Evidence is securely stored using:

- Encrypted Storage
- Database Records
- Secure Media Folder

---

## Stage 7 – Archive

Closed investigation evidence is archived.

Archived evidence remains available for future reference.

---

## Lifecycle Benefits

- Secure Investigation
- Complete Traceability
- Better Evidence Management
- Reliable AI Analysis
- Improved Case Handling

---

## Expected Result

Every digital evidence file should follow a complete lifecycle from collection to archival while maintaining security, integrity and traceability.
