# AIDEX Dashboard Components

## Introduction

Dashboard Components are reusable interface elements used across the AIDEX dashboard.

These components help maintain a consistent design and improve navigation.

---

## 1. Navbar Component

The Navbar is the top navigation area.

Main Elements:

- AIDEX Logo
- System Name
- Search Box
- Notification Icon
- Profile Image
- Username
- Role
- Logout Button

Purpose:

- Display system identity
- Provide quick search
- Show notifications
- Display logged-in user information
- Allow secure logout

---

## 2. Sidebar Component

The Sidebar provides module navigation.

Menu Items:

- Dashboard
- Cases
- Evidence
- Reports
- AI Analysis
- Users
- Profile
- Settings
- Logout

Purpose:

- Move between system modules
- Display role-based menu options
- Improve navigation speed

---

## 3. Statistics Card Component

Statistics Cards display important counts.

Example Cards:

- Total Cases
- Open Cases
- Closed Cases
- Pending Cases
- Total Evidence
- Pending Verification
- Total Reports
- Active Users

Card Structure:

- Icon
- Title
- Number
- Description
- View Details Link

---

## 4. Table Component

Tables display structured records.

Examples:

- Case Table
- Evidence Table
- Report Table
- User Table
- Audit Log Table

Common Columns:

- ID
- Name or Title
- Status
- Assigned User
- Date
- Action

Common Actions:

- View
- Edit
- Download
- Verify
- Generate Report

---

## 5. Button Component

Buttons allow users to perform actions.

Main Buttons:

- Add Case
- Upload Evidence
- Verify Evidence
- Generate Report
- Edit Profile
- Approve Account
- Reject Request
- Logout

Button Types:

- Primary Button
- Secondary Button
- Success Button
- Warning Button
- Danger Button

---

## 6. Search Component

The Search Component helps users find records.

Search Options:

- Search by Case ID
- Search by Case Number
- Search by Case Title
- Search by Evidence ID
- Search by Username
- Search by Badge ID

---

## 7. Notification Component

Notifications display important updates.

Notification Types:

- Information
- Success
- Warning
- Error
- Security Alert

Examples:

- Evidence uploaded successfully
- Case created successfully
- Account approval pending
- Invalid login attempt
- Evidence verification completed

---

## 8. Alert Component

Alerts show urgent information.

Examples:

- Suspicious login detected
- Evidence hash mismatch
- Unauthorized access attempt
- Account locked
- File upload rejected

---

## 9. Form Component

Forms collect user data.

Main Forms:

- Login Form
- Registration Form
- Case Form
- Evidence Upload Form
- Profile Edit Form
- Report Generation Form

Form Elements:

- Text Input
- Email Input
- Password Input
- Dropdown
- File Upload
- Text Area
- Submit Button

---

## 10. Chart Component

Charts display analytical information.

Possible Charts:

- Cases by Status
- Cases by Month
- Evidence by Type
- Reports Generated
- User Activity
- AI Analysis Results

---

## 11. Profile Component

The Profile Component displays user information.

Profile Details:

- Profile Photo
- Full Name
- Username
- Email
- Phone Number
- Department
- Badge ID
- Role
- Account Status

---

## 12. Footer Component

The Footer displays project information.

Footer Content:

- AIDEX
- Version 1.0
- GTU Diploma Minor Project
- Team Member Names
- Copyright

---

## Expected Result

All dashboard components should have a common design, clear labels and role-based access.
