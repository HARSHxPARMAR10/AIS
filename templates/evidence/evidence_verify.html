Verification Checklist

Recommended review points before submission.

Confirm File Integrity

Review the SHA-256 hash and run the integrity check from the evidence detail page when required.

Inspect the Original File

Open or download the source file and confirm that it is readable and complete.

Check Case Relevance

Confirm that the evidence belongs to the linked case and supports the investigation context.

Record Clear Notes

Document objective findings, especially for rejection or corruption decisions.
