# AIDEX Registration Page Design

## Introduction

The Registration Page allows authorized users to create a new account within the AIDEX system. The page is designed with a modern two-column layout using Bootstrap 5 to provide a professional and user-friendly registration experience.

---

## Objectives

The Registration Page is designed to:

- Register new users securely
- Collect official user information
- Assign user roles
- Upload profile photographs
- Validate user input
- Maintain responsive design

---

## Registration Fields

The registration form includes the following fields:

- Full Name
- Username
- Email Address
- Password
- Phone Number
- Department
- Badge ID
- User Role
- Profile Photo

---

## User Interface Features

The page includes:

- Modern Bootstrap Card
- Responsive Two Column Layout
- Professional Color Theme
- Secure Registration Button
- Form Validation
- Bootstrap Alerts
- Mobile Responsive Design

---

## Validation

The system validates:

- Required Fields
- Email Format
- Username Availability
- Password Input
- Badge ID
- Role Selection

---

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Django Forms
- Django Template Engine

---

## Expected Result

The Registration Page allows users to create a secure account with proper validation and a professional user interface.
